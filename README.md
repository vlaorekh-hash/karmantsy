# Карманцы

Прототип игры для двоих: у каждого в телефоне свои карманцы, бои Математиков, Грамотеев и Воинов (камень, ножницы, бумага), ставки вкладышами и альбом коллекции.

Открыть: https://vlaorekh-hash.github.io/karmantsy/

Как играть вдвоём:
1. Откройте ссылку в Safari на обоих телефонах и добавьте на экран «Домой» (Поделиться → На экран «Домой»).
2. Разбейте яйцо, назовите героев, выберите стартовый набор (динозавры или кошки — разные у двоих).
3. Один нажимает «Создать бой», второй вводит код или сканирует QR-код.

Связь идёт напрямую между телефонами (WebRTC через PeerJS). Надёжнее всего в одной сети Wi-Fi.
Для проверки на одном компьютере: откройте страницу с `?local` в двух вкладках.

Библиотеки в `vendor/`: PeerJS 1.5.4 и qrcode-generator 1.4.4, обе под лицензией MIT.

## Кабинет карточек

https://vlaorekh-hash.github.io/karmantsy/admin.html — добавление и правка карточек и коллекций, загрузка иллюстраций.
Каталог хранится в `cards.json`, картинки в папке `cards/`. Кабинет публикует изменения одним коммитом через GitHub API
с личным токеном (Contents: Read and write только для этого репозитория). Требования к картинкам — на вкладке «Требования».
